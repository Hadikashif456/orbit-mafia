# Frontend

Owner: Eman Fatima.

React dashboard. 4 screens only.

1. Crew board: 4 astronaut cards, CRI as a large number, colour status. At risk astronaut is impossible to miss.
2. Astronaut detail: heart rate, HRV, sleep, radiation, exercise, mood. 7-sol and 30-sol trends.
3. Risk alert and AI copilot: why CRI fell, what risk is rising, one recommended action. Never an alert with no reason.
4. Demo mode Day 140 to 145: play, pause, step. Big trigger button for the radiation event. CRI falls 82 to 61 live.

Use the real API in `docs/API_CONTRACT.md`. No hard coded numbers in the dashboard.
Label synthetic data on screen.
Readable on a projector, works on laptop and phone.
